3 The TARA Framework

Background. Split conformal prediction: let D_cal = {(X_i, Y_i)}_{i=1}^n be a calibration set drawn exchangeably from P. Given a nonconformity score s, the conformal p-value for a test point is p(X_{n+1}, y) = (1 + sum_i 1{s_i >= s(X_{n+1}, y)}) / (1 + n). Under exchangeability, P{Y_{n+1} in C_alpha(X_{n+1})} >= 1 - alpha. In the CHSH Bell scenario, Alice and Bob choose settings x, z in {0,1} and observe outcomes a, b in {-1,+1}; S = E00 + E01 + E10 - E11 with E_xz = E[ab | x, z]. Bounds: classical (LHV) |S| <= 2; quantum (Tsirelson) |S| <= 2*sqrt(2) ~ 2.828; algebraic (PR-box) |S| <= 4.

3.1 TARA-k: Batch Detection
TARA-k treats quantum detection as one-class classification against an LHV null manifold. The core insight is that under the null hypothesis (classical correlations), conformal p-values should be uniformly distributed on [0,1], while quantum correlations systematically deviate from this uniformity. We quantify this deviation using the Kolmogorov-Smirnov (KS) statistic.
LHV Null Manifold. The local hidden variable null distribution H0 consists of all correlation matrices E = [E00, E01, E10, E11] achievable by classical local models: E_xz^LHV = integral over Lambda of A(x, lambda) B(z, lambda) d mu(lambda), where A, B are deterministic response functions. This manifold satisfies |S| <= 2 and includes detection, memory, and communication loophole models.
Feature Vector. For a dataset D of CHSH measurements, define f(D) = [|S|, p_A, p_B, p_AB, p_empty, TARA-k, E|C_alpha|], where |S| is the absolute CHSH parameter; p_A, p_B, p_AB, p_empty are marginal click rates capturing detection efficiency; TARA-k is the KS-distance calibration statistic; and E|C_alpha| is the expected conformal prediction set size at level alpha.
The TARA-k statistic. Given calibration p-values {p_1..p_n} computed against LHV-trained models, with empirical CDF F_LHV(t), and test p-values {q_1..q_m} with empirical CDF F_test(t): TARA-k = sup_{t in [0,1]} |F_LHV(t) - F_test(t)|. Under exchangeability, the two-sample KS test gives a distribution-free significance test: P(TARA-k > c_alpha * sqrt((n+m)/(nm))) <= alpha, where c_alpha is the KS critical value (c_0.05 ~ 1.36). For quantum data, p-values deviate from uniformity because quantum correlations lie outside the LHV-trained model's support, yielding elevated TARA-k.
TARA-k protocol (Algorithm 1). Input: LHV calibration data D_LHV, test data D_test, significance alpha. Phase 1 (Feature Extraction): for every dataset compute S, the click rates, TARA-k and E|C_alpha|, and form f(D). Phase 2 (Calibration): fit a one-class Elliptic Envelope on {f(D)} for D in D_LHV and estimate a threshold tau_alpha for the desired false-positive rate. Phase 3 (Detection): compute anomaly score a = OneClass(f_test) and TARA-k; if a > tau_alpha or TARA-k > KS_alpha return "Quantum", else return "Classical".

3.2 TARA-m: Streaming Detection
While TARA-k requires batch data collection, many quantum applications demand real-time monitoring of streaming data. TARA-m uses betting martingales, which provide sequential testing with anytime-valid type-I error control. At each time step we receive a conformal p-value and place a bet on whether the null (LHV) hypothesis is false. If we are correct (quantum data), wealth grows; if incorrect (classical data), wealth shrinks.
Betting Martingale. Given conformal p-values p_1, p_2, ..., the wealth process is M_t = prod_{i=1}^t (1 + beta_i (p_i - 1/2)), M_0 = 1, where beta_i in [-2, 2] is chosen before observing p_i. Kelly-style betting sets beta_i = lambda * sign(p_i - 1/2), with lambda in (0,1) controlling aggression.
Validity. Under H0, if p_t | F_{t-1} ~ Unif(0,1), {M_t} is a non-negative supermartingale with E_H0[M_t] <= 1. Ville's inequality gives P_H0(exists t: M_t >= 1/alpha) <= alpha, so we can reject the null at any stopping time tau when M_tau >= 1/alpha, without fixing the sample size in advance. Equivalently, log M_t drifts upward under the quantum alternative and the threshold is log(1/alpha).
TARA-m protocol (Algorithm 2). Input: stream of measurements, threshold tau = 1/alpha. Initialize M_0 = 1. For t = 1, 2, ...: receive outcome (x_t, z_t, a_t, b_t); compute the conformal p-value from the LHV-calibrated model; set beta_t = lambda * sign(p_t - 1/2); update M_t = M_{t-1} (1 + beta_t (p_t - 1/2)); if M_t >= tau return "Quantum detected at time t".
Calibration hygiene. Calibration data must come from a different distribution/source than the test data; same-distribution calibration inflates apparent detection performance (by up to 44 percentage points in our experiments).
